# AI Chat Model using Hugging Face + LangChain

This project demonstrates how to build a simple AI chatbot using:

- LangChain
- Hugging Face Inference API
- Open Source LLM (`openai/gpt-oss-120b`)
- Python

The chatbot accepts user prompts and generates AI responses directly from a Hugging Face hosted model.

---

# Features

- Open-source AI model
- LangChain integration
- Hugging Face API support
- Environment variable security using `.env`
- Simple and beginner-friendly code
